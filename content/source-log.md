# Source log

Every notice already reported from the official portals, so the next check only
reports what's new. Follow the content drafting rules in `AGENTS.md`.

How to use it:

- Before reporting a notice, look for it here (by advertisement number or title).
  If it's listed, report it again only if something changed (a new date,
  corrigendum, result and so on), and add a new row for that change.
- "Date seen" is the day the notice was first read on the official site.
- "Status" says what happened next: `reported`, `drafted`, `published`, or
  `skipped` (with the reason).
